# Rommat Try Out V3

Versión Node.js/Express inspirada en la web y en la referencia visual facilitada:
- hero industrial oscuro
- cabecera blanca y amarillo/dorado
- cajas de contacto translúcidas
- estadísticas amarillas
- servicios, nosotros, marcas, proyectos, proceso, FAQ, CTA y contacto
- efectos hover y pequeñas animaciones
- responsive
- formulario POST /api/contacto

## Arranque
Node.js 18+:
npm install
npm start

Abrir:
http://localhost:3000

El formulario queda preparado para conectarse a correo/CRM; por defecto registra la solicitud en la consola.
